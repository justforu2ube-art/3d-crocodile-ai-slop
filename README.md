# Nile Crocodile — Interactive 3D Procedural Viewer

An interactive, procedurally sculpted 3D Nile Crocodile (*Crocodylus niloticus*) built with Three.js, React, and TypeScript, featuring articulated reptile kinematics, procedural PBR hide textures, blinking eyes, `.GLB` export, and shareable pose/camera deep links.

## Publish Your Live Browser Link on GitHub Pages

This repository includes an automatic GitHub Pages deployment workflow (`.github/workflows/deploy-pages.yml`).

1. **Push** your latest commits to the `main` branch on GitHub.
2. Open your repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.

Within ~1 minute, GitHub will publish your live browser link at:

```text
https://<your-github-username>.github.io/<your-repo-name>/
```

You can also click **Share Link** inside the bottom control dock at any time to copy a URL that restores your exact camera angle, pose, animation mode, and environment for anyone who opens it.
